# Mini Translation Tracker - VerbaDesk

Автори: Нікітіна Олександра Володимирівна, Пащенко Ярослава Олегівна

## Про проєкт
VerbaDesk — це внутрішня MVP вебсистема для невеликого бюро перекладів. Вона призначена для централізованої реєстрації, відстеження та координації виконання запитів на переклад від клієнтів.
